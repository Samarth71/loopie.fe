Loopie - run locally
1. Install Node.js (v18+)
2. In this folder run:  npm install
3. Then run:           node server.js
4. Open http://<your-computer-IP>:3000 on both devices (same Wi-Fi).
   Friends on the same network appear automatically. Different network: use the 4 digit code (Pair tab).
To use online, deploy this folder to Render / Railway / Fly.io (start command: node server.js).
